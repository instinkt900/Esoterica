# Upstream sources the Linux build drops.
#
# Hand-maintained. One glob or path per line, matched against the repo-relative path.
# '#' starts a comment.
#
#   **/     zero or more leading directories
#   **      anything, including '/'
#   *       anything except '/'
#
# A pattern that matches nothing is reported as a problem, because it is usually a leftover
# from an upstream rename. Keep this file honest: every line here should be doing work.
#
# Say *why* a file is excluded. The next person to read an upstream merge diff needs it.

#-------------------------------------------------------------------------
# Windows platform implementations
#-------------------------------------------------------------------------

# Upstream puts platform code in <System>/Platform/<System>_Win32.cpp. Each of these gets a
# _Linux sibling, listed in LinuxSources.txt. See Docs/Linux/00-Conventions.md rule 1.
**/*_Win32.cpp

# Application entry points live in a Win32/ directory rather than taking a suffix. The glob
# above already covers today's files; this one catches an unsuffixed file added to those
# directories later.
**/Win32/**

# Windows implementations that carry no suffix at all. Same rule as the two globs above - the
# file is a Windows implementation and its _Linux sibling is listed in LinuxSources.txt - but
# the name gives the generator nothing to match on, so each one needs a line of its own.

# 552 lines of COM IFileDialog. The shared header is SystemDialogs.h, which both sides include;
# excluding the .cpp drops only the Windows implementation. Sibling: SystemDialogs_Linux.cpp.
Code/EngineTools/Core/SystemDialogs.cpp
