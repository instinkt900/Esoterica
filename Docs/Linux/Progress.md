### 2026-08-25 — Defer the External.zip download until Phase 2
**Context:** the plan flagged the External.zip (~283 MiB) download as Phase 0's first open
item — the LLVM version the Reflector needs is baked into the zip, not into `LLVM.props`
(see [03-Dependencies.md](03-Dependencies.md)).
**Decision:** do not download it during Phase 0. Pin LLVM and fetch it in Phase 2, when the
compiler toolchain is actually being built.
**Rationale:** Phase 0 needs only the host toolchain (clang 19.1.1 and gcc are already
installed on the development machine); the download is large, and the version choice belongs
with the Phase 2 task that must build against it.
**Alternatives rejected:** downloading it now — weeks of unused disk, and it would pre-empt
the Phase 2 investigation that the pinning decision depends on.

  that is a deliberate behaviour fix, and it is recorded here rather than hidden.
